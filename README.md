# أنا جوال — نسخة أولية

هذه واجهة تجريبية لإدارة فعاليات البرنامج والطلاب والمهام. افتح `index.html` مباشرة لتجربتها.

## نشر على GitHub Pages
1. افتح مستودع `ana-jawwal-16` ثم **Add file > Upload files**.
2. ارفع `index.html` و `README.md` في جذر المستودع، ثم اضغط **Commit changes**.
3. افتح **Settings > Pages** واختر **Deploy from a branch** ثم `main` و `/ (root)` واحفظ.
4. انتظر ظهور رابط الموقع في صفحة Pages.

## مهم
- التخزين محلي داخل المتصفح، وليس قاعدة بيانات مشتركة.
- لا يوجد تسجيل دخول أو إرسال بريد أو مزامنة متعددة المستخدمين.
- لا تدخل معلومات حقيقية أو حساسة قبل تطوير حماية وتخزين آمنين.
